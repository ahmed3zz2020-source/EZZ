# 🧰 المهارات المثبّتة (Skills)

⭐ المهارة دي **مش شيفرة** — دي ملف تعليمات (SKILL.md) بيخلي الوكيل يعرف ينفّذ مهمة معيّنة صح من أول مرة.

## ⭐ find-skills (من vercel-labs/skills)
**وظيفتها:** لما أحمد يقول «إزاي أعمل X» أو «فيه مهارة تعمل X» ⇒ بتدوّر في مكتبة المهارات المفتوحة، تلاقي اللي يناسب، وتثبّته.

**التثبيت (أمر واحد):**
```bash
npx -y skills add vercel-labs/skills --skill find-skills -y
mkdir -p /workspace/.skills && cp -r .agents/skills/find-skills /workspace/.skills/
```

**ليه نافع:** بدل ما نبني كل قدرة من الصفر (كريدت + وقت)، نحمّل تعليمات جاهزة ومجرّبة.
** ⭐ متى يشتغل:** المهارات بتتقرأ في بداية الجلسة ⇒ اللي ثبّته دلوقتي بيظهر في **الجلسة الجاية**.
