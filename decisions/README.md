# Decisions — سجل القرارات

كل قرار في ملف: `D-0001-<عنوان-مختصر>.md`.
**الحالات:** `approved` (معتمد) · `proposed` (مقترح) · `pending` (معلق) · `rejected` (مرفوض) · `superseded` (مستبدل).
⛔ لا يُحذف قرار — يُعلَّم superseded ويبقى مرجعاً.

القالب:
```
# D-0001 — <العنوان>
- التاريخ: YYYY-MM-DD
- الحالة: approved
- صاحب القرار: المالك / CEO
- الإعداد: <الوكيل>
- القرار: <سطر>
- السبب: <لماذا>
- الأثر: <ما يتغيّر>
- البدائل المرفوضة: <…>
-capes: metrics/keys/databases affected
```
