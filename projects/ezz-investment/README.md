# 🚀 محفظة عز استثمار — README

> ⭐ **بنية تحتية متعددة المحافظ من اليوم الأول** — محفظة واحدة دلوقتي (عز استثمار)، والباقي كيان مستقل يُضاف بنفس السجل.
> ⛔ **المستودع عام ⇒这里面 القواعد والبنية فقط. الأرقام الحقيقية (رأس المال · المراكز · الأرباح) في KV خاص (`ezz-investment`) + نسخة محلية.**

---

## 1) التشغيل

| الأمر | الوظيفة |
|---|---|
| `python3 engine.py --slot intraday` | تقرير الجلسة (١٣:٤٥ القاهرة) — أوامر تنفيذ جاهزة |
| `python3 engine.py --slot night` | مسح الليلة (٢٣:٠٠ القاهرة) — خطة الجلسة الجاية |
| `python3 engine.py --slot night --dry-run` | بدون إرسال (معاينة) |
| `python3 engine.py --fill <ORDER_ID> --price <سعر>` | **تسجيل تنفيذ مؤكد من المالك** |

**المتطلبات البيئية:** `OCTA_ADMIN_TOKEN` · `CLOUDFLARE_API_TOKEN` · `OFFICE_TELEGRAM_TOKEN` · `EZZ_INITIAL_CAPITAL` · `TELEGRAM_CHAT_ID`
(كلها في أسرار المنصة ⇒ متاحة تلقائياً في جلسات الـcron.)

## 3) طبقة الفهم المستقلة ⭐

**نتيجة OCTA مدخل عندنا، مش قرار.**

| العامل | الوزن | إزاي بيتحسب |
|---|---|---|
| زخم momentum | ٢٦٪ | أداء ١ش/٣ش/٦ش/سنة + موقع السعر من EMA20/50/200 + RSI (تصحيح لـ ٧٥ فوق) |
| جودة quality | ٢٥٪ | ROE · هامش صافي · D/E (بنوك/مقاولات بتخفف العقوبة) · عائد التوزيعات |
| قيمة value | ١٦٪ | **نسبية** — P/E و P/B ÷ متوسط القطاع (مش مطلق) |
| سيولة liquidity | ١٣٪ | القيمة السوقية (مقياس لوغاريتمي) + الحجم النسبي |
| مخاطرة risk | ١٤٪ | بيتا + ATR% + مستوى المخاطرة |
| محفّز catalyst | ٦٪ | عائد التوزيعات + أحداث مسجّلة |

- ⭐ **تغطية البيانات محسوبة** — لو عامل ناقص ⇒ الدرجة بتتحسب على الموجود بس **والتغطية بتتنزل** ⇒ والبوابة بترفض أي سهم تغطيته أقل من ٥٥٪.
- ⭐ **كشف التعارض:** زخم قوي + جودة ضعيفة · جودة عالية + زخم ميت · رخيص بلا محفّز · سيولة ضعيفة · مخاطرة عالية · RSI فوق ٧٥ · تغطية ضعيفة.
- ⭐ **المقارنة مع OCTA:** `divergence = درجتي − نتيجة OCTA` — الفرق بيتبان في التقرير (والفرق الكبير بيبقى سؤال مش إجابة).

## 4) التخزين

| المكان | إيه فيه | ⭐ |
|---|---|---|
| `ezz-investment/portfolio/ezz-investment` (KV) | الدفتر الكامل | المصدر الأساسي |
| `ezz-investment/portfolio/meta` (KV) | خط الأساس (نقطة البداية + قيم المعايير) | ⭐ ثابت |
| `ezz-investment/journal/<date>` (KV) | سجل القرارات (append-only) | دائم |
| `ezz-investment/reports/<date>-<slot>` (KV) | نص كل تقرير | أرشيف |
| `/opt/ezz-investment-state/` (محلي) | نسخة احتياطية من الدفتر + السجل | ⭐ بيشتغل لو KV اتقفل |

⛔ **سقف KV:** ١٠٠٠ write/يوم على مستوى الحساب كله (مش المساحة) ⇒ البوت الذهبي بياخد ~٥٧٦ ⇒ فاضل ~٤٢٠ ⇒ استهلاكنا ~٦/يوم ✔.
⭐ **لو KV رجّع 429** ⇒ المحرك بيكمل شغّان بيكتب محلياً — **مش بيقف**.
