# 🎬 خط إنتاج الفيديو — «محفظة 100 ألف»

⭐ **الفلسفة:** أقل كريدات ⇒ صفر توليد صور بالذكاء الاصطناعي · HTML/CSS → Chromium → صورة → ffmpeg + صوت مُجمَّع (TTS).
| الخطوة | الأداة | التكلفة |
|---|---|---|
| المشاهد | HTML/CSS + Chromium (خط Cairo العربي) | **صفر** |
| الصوت | TTS مُجمَّع (١٠ مشاهد في نداء واحد) | نداء واحد لكل فيديو |
| المونتاج | ffmpeg (zoompan + concat + aac) | **صفر** |

**الاستخدام:**
```bash
python3 extract.py          # يستخرج الراوي من سكريبت الوكيل + يدمج الجزء البصري
python3 tts.py v1.json      # يولّد الصوت (١٠ مشاهد/نداء) + durations.json
python3 build.py v1.json    # المشاهد + الفيديو + الغلاف
```
**الفيديوهات:** `v1.json` (الحصة الأولى · ١٢ مشهد · 16:9) · `r1/r2/r3.json` (ريلز · ٥ مشاهد · 9:16).
⛔ ممنوع: ذكر أي اسم أداة ذكاء اصطناعي في أي نص · ادعاء جودة غير متحقَّقة · نشر (فئة C).
